# Proyecto Formula 1 API

Este proyecto es una aplicación web desarrollada en JavaScript que utiliza Firebase para la gestión de datos.

- Tecnologías utilizadas

JavaScript (ES6+): Lenguaje principal del proyecto.

Firebase: Base de datos y autenticación.

CSS: Estilos de la interfaz.

- Estructura del proyecto

app/: Contiene la lógica principal de la aplicación.

app.mjs: Archivo principal.

firebase/conexionFirebase.mjs: Configuración de Firebase.

middleware/subidaArchivos.mjs: Manejo de subida de archivos.

public/css/: Archivos CSS para los diferentes módulos.

package.json: Configuración del proyecto y dependencias.

- Funcionalidades

Gestión de usuarios con Firebase.

Subida y almacenamiento de archivos.

Estilos personalizados para la interfaz.
